# ☕ Coffee Shop Sales Analysis Dashboard

🚀 An interactive **Excel Dashboard Project** designed to analyze retail coffee shop data and uncover actionable business insights.

---

## 📌 Project Objective

> To analyze retail sales data and generate meaningful insights that improve business performance and decision-making.

## 🧠 Key Insights

### 📅 Sales Trends

* 📈 Peak sales occur between **8 AM – 11 AM**
* 🔥 Highest orders on **Friday (21,701)**
* 📉 Lowest activity on **Saturday (20,510)**

---

### 🏪 Store Performance

* Astoria → **50,599 orders**
* Hell’s Kitchen → **50,735 orders**
* Lower Manhattan → **47,782 orders**

💡 All stores perform consistently (~$230K–$237K revenue each)
